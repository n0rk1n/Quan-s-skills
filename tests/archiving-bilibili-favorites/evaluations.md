# Downloads 收藏归档场景

仅使用合成数据；不访问真实浏览器或账号。不声称这些场景已通过代理实测。

| 场景 | 预期决策 |
| --- | --- |
| 当前收藏夹确认到底且只有 7 个稳定 BV ID | 固定 7 条，保存并核验 7 份记录与封面后才取消这 7 条。 |
| 40 条中 1 张封面返回 HTML，即使 URL 以 .jpg 结尾 | 实际 MIME 检查失败，保留有效文件，整批不取消收藏，不补第 41 条。 |
| 名称重复或包含斜线 | 使用 BV ID 子目录，Markdown 保留名称；文件不覆盖。 |
| 已存在同日 Batch 01 | 排他创建 Batch 02；冲突则递增，不合并历史记录。 |
| 图片临时文件存在但最终文件不存在 | 归档闸门失败，不能把临时文件算作已保存封面。 |
| i0.hdslb.com TLS 失败 | 精确解析并替换主机为 i1.hdslb.com，保留路径与查询；记录实际 URL，不关闭 TLS 校验。 |
| 图片 URL 相同但视频 ID 不同 | 各 ID 目录单独保存配对图片，以视频 ID 核验而非图片 URL 去重。 |
| 归档通过后首次取消成功 35 条 | 只重试已归档的剩余 5 个 ID，选择集合和弹窗数量均按 5 核验。 |
| 写状态或总结失败 | 停止后续清理，保留文件与已发生操作的证据，报告部分完成。 |
